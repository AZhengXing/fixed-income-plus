# 源数据说明

本目录是网页的统一研究数据入口。原始文件、公开接口快照和解析结果都保存在这里，网页不再把主要数据散落在组件代码中。

## 目录结构

```text
source-data/
├── reports/                  # 基金管理人季度报告 PDF
│   ├── 110017/               # 易方达增强回报债券 A
│   ├── 675111/               # 西部利得汇享债券 A
│   └── 001235/               # 中银国有企业债 A
├── api/                      # 天天基金公开持仓接口的原始响应快照
│   └── <基金代码>/
│       ├── bond-holdings-<年份>.js
│       └── stock-holdings-<年份>.js
├── processed/                # 由脚本生成的可复核 JSON / CSV
│   ├── research-data.json
│   ├── quarterly-summary.csv
│   └── disclosed-positions.csv
├── SOURCES.csv               # 每个源文件的网址、抓取日期和 SHA-256
└── README.md
```

## 来源优先级

1. **季度报告 PDF**：法定披露原文，是业绩、资产分类、基金规模和披露边界的主依据。
2. **公开持仓接口快照**：用于机器化还原证券代码、名称、权重和历史表格；与季度报告同一报告期交叉核对。
3. **解析结果**：由 `scripts/build_research_data.py` 从上述文件生成，不是独立来源。

季度报告由基金管理人发布，本仓库保存的是东方财富公告镜像；公开持仓快照来自天天基金的 `FundArchivesDatas.aspx` 接口。每个文件的具体来源见 `SOURCES.csv`。

## 披露边界

- 普通债券：季度报告只披露占净资产比例最高的前五名，不能据此还原全部普通债券个券。
- 可转债：公开持仓快照列示报告期可取得的转债/可交换债明细；合计可能因四舍五入、转股期状态或数据口径差异低于季报的可转债分类总额。
- 股票：季度报告仅披露前十大股票，不代表全部股票持仓。
- 现金：银行存款和结算备付金、买入返售金融资产及其他资产均为汇总项目。

网页中的“本季未列示”只表示证券不再出现在相同披露表中，不自动等同于清仓。

## 更新流程

新季报披露后：

1. 将 PDF 保存到 `reports/<基金代码>/<季度>.pdf`。
2. 将当年债券、股票接口响应保存到 `api/<基金代码>/`。
3. 在 `scripts/build_research_data.py` 中增加季度、报告编号和经核对的收益摘要。
4. 运行：

```bash
python3 scripts/build_research_data.py
```

5. 检查 `processed/` 的变动，再运行网页构建。

解析脚本依赖系统命令 `pdftotext`。生成文件采用 UTF-8；两个 CSV 带 UTF-8 BOM，便于直接用 Excel 打开。

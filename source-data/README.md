# 源数据说明

本目录是网页的统一研究数据入口。原始文件、公开接口快照和解析结果都保存在这里，网页不再把主要数据散落在组件代码中。

## 目录结构

```text
source-data/
├── reports/                  # 基金管理人季度报告 PDF
│   ├── 110017/               # 易方达增强回报债券 A
│   ├── 675111/               # 西部利得汇享债券 A
│   └── 001235/               # 中银国有企业债 A
├── api/                      # 天天基金公开持仓接口的原始响应快照
│   └── <基金代码>/
│       ├── bond-holdings-<年份>.js
│       └── stock-holdings-<年份>.js
├── processed/                # 由脚本生成的可复核 JSON / CSV
│   ├── research-data.json
│   ├── quarterly-summary.csv
│   └── disclosed-positions.csv
├── 2026Q3-sources.json        # Q3 官方入口、归档来源、披露及接口状态
├── SOURCES.csv               # 每个源文件的网址、抓取日期和 SHA-256
└── README.md
```

## 来源优先级

1. **季度报告 PDF**：法定披露原文，是业绩、资产分类、基金规模和披露边界的主依据。
2. **公开持仓接口快照**：用于机器化还原证券代码、名称、权重和历史表格；与季度报告同一报告期交叉核对。
3. **解析结果**：由 `scripts/build_research_data.py` 从上述文件生成，不是独立来源。

季度报告由基金管理人发布。历史 15 份为东方财富公告镜像；2026Q3 易方达、中银为官网 PDF，西部利得为公告镜像（官网下载返回 503），官方链接仍保留于 `2026Q3-sources.json`；公开持仓快照来自天天基金的 `FundArchivesDatas.aspx` 接口。每个文件的具体来源见 `SOURCES.csv`。

## 披露边界

- 普通债券：季度报告只披露占净资产比例最高的前五名，不能据此还原全部普通债券个券。
- 可转债：公开持仓快照列示报告期可取得的转债/可交换债明细；合计可能因四舍五入、转股期状态或数据口径差异低于季报的可转债分类总额。
- 股票：季度报告仅披露前十大股票，不代表全部股票持仓。
- 现金：银行存款和结算备付金、买入返售金融资产及其他资产均为汇总项目。

网页中的“本季未列示”只表示证券不再出现在相同披露表中，不自动等同于清仓。

## 2026Q3 更新与缺口

- 三只基金官方均已披露 Q3 季报，18 份报告中的新增三份均已取得，无估算财务值。
- Q3 使用季报 3.1 / 3.2.1（全份额规模 / A 类收益）、5.2（股票净资产占比）、5.4（债券分类）、5.5（前五债券）及转股期转债附注。原有 15 个历史快照保持原值。
- 新持仓接口响应未取得（原端点返回 404）；保留旧快照及原抓取日期，不覆盖历史文件、不伪造接口响应。Q3 个券直接取自 PDF；转债明细不等同于全部可转债资产。
- 证券按代码比较，沿用新增披露 / 增减 / 本季未列示；跨来源披露表变化不能推断交易。债券总额包含可转债，政策金融债是金融债子集，均不重复加总。现金仍以报告金额除以全份额净资产。
- 西部利得、中银分别于 7 月 27 日、9 月 21 日调整业绩基准。Q3 超额使用季报公布的基准，历史数值不追溯改写。中银经理名单按 Q3 报告，并非实时名单。
- `2026Q3-sources.json` 保存官方地址、公告镜像及取得状态；`SOURCES.csv` 记录归档文件 SHA-256 与本次取得日期，历史文件日期不变。

## 更新流程

新季报披露后：

1. 将 PDF 保存到 `reports/<基金代码>/<季度>.pdf`。
2. 将当年债券、股票接口响应保存到 `api/<基金代码>/`。
3. 增加季度与报告元数据。Q3 由 `parse_q3` 直接解析 PDF 收益与持仓，`2026Q3-sources.json` 仅保留来源、披露状态及经核对的定性摘要；旧季度继续沿用历史解析路径。
4. 运行：

```bash
python3 scripts/build_research_data.py
```

5. 运行 `python3 scripts/validate_research_data.py`，检查 `processed/` 的变动，再运行网页构建。

解析脚本依赖系统命令 `pdftotext`。生成文件采用 UTF-8；两个 CSV 带 UTF-8 BOM，便于直接用 Excel 打开。
